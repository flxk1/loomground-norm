# Concrete dev/CI resolution of the abstract ranges in pyproject.toml. Kept out
# of package metadata so the built distribution stays index-clean. Immutable git
# revisions only — never a floating branch — so a build can be reproduced.
#
# Dependency order (see RELEASING.md): norm sits between the deontic language /
# the solver and the domains that consume it. For LOCAL development with the
# sibling checkouts present, conftest.py adds their src/ dirs to the path, so
# `pytest` runs with no pins installed.
#
# These are the same revisions loomground-legal pins, so the two planes resolve
# to one upstream set. Without them `pip install .` looks for loomground-solver
# on the index, finds nothing, and the job fails before a single test runs.
#
# loomground-governance is not a direct dependency of this plane: loomground_solver
# imports it at module import time and declares it in its own metadata, but it is
# not on an index — so it has to be named here as a direct git requirement for
# pip to resolve the solver install at all.
